# 那我呢

> 历史创作示例：保留原有立意和结构。以下未附出处的事实、数字或流行趋势，制作新片前需重新核实；星座性格仅作娱乐表达。

**一句话核心**：双鱼座总是先替别人找好理由——别人的难处他全懂了，自己的难过却没地方放。
落点：双鱼座本来就是两条鱼，被一根绳系着尾巴。一条总游向别人；另一条，是你自己。→「那我呢？我今天开心吗？」

**框架（真实天文）**：双鱼座是两条鱼，尾巴被一根绳子系在一起；绳结那颗星叫 Alrescha（α Psc），阿拉伯语里就是"绳子"。
双鱼座很暗，最亮的星（η Psc）只有约 3.6 等。

**视觉母题**：一条光做的鱼（他）。全片它尾巴后面都拖着一根细细的光线，一直伸到画外 —— 观众以为是光尾巴；
结尾拉远：线的另一头，系着另一条暗淡的、蜷着的鱼 —— 他自己。两条鱼 + 绳 = 双鱼座星图。
颜色系统：青白（珍珠色）= 他；琥珀 = 你（别人）；猩红 = 生气 / 伤人的话；玫瑰粉 = 他自己的感受（那条被忘掉的鱼）。

**结构**
1. 墨（钩子）：黑水里一滴猩红的墨坠下，炸成蘑菇云一样的墨团（"刚准备生气"）→ 光鱼游过，尾流把红墨冲淡成一片清水（"就先替对方找好了理由"）。
2. 下沉的话（水下 + 焦散光）：伤人的话像石头一样沉下来，带着气泡；光鱼游过去，绕一圈，红光变冷，旁边浮出它替对方想的理由。
   "我也不容易"沉下来时，它直接游过去托住。→ 海底铺满了"你的难处"，每块都被它照亮了；它掉下的一颗玫瑰色的泪滴，找不到地方落，一直往黑里沉。
3. 焦点（散景人群）：一群琥珀色的光（一群人聊天）在焦外跳动，飘着零碎的话；有一句"我其实挺爱吃桂花糕"被它悄悄收起来。
   一颗光突然安静、暗下去 → 焦点从人群拉到那颗光上，全世界虚掉，只有它和光鱼清楚。
4. 看海（想象力，全片招牌）："以后一起去看海吧" → 线框草图搭出一片海 → 上色成真实的落日海面（日落、波光、耳机里的歌、两个牵手的剪影）→
   等了很久没下文：画面定格、褪色，日期计数 第 1 天 → 第 97 天 → 画面折回线框，缩成一粒光，悬在半空没地方落。
5. 落下（夜海上的灯）：很多粒"期待"的光在夜空里漂 → 每兑现一个小约定，海面上亮起一个落点，一粒光落下来，水面荡开涟漪 + 拉长的倒影；
   做不到的那件，一句认真的解释，它也稳稳落下了。
6. 倒影（真话）：平静水面上立着冷白的"都可以"，水里的倒影却写着"我想去另一家"；"没关系" ↔ 倒影"我在等你道歉"。
   → 倒影的字破水而出，翻上来，替换掉水面上那句。
7. 双鱼：拉远，光鱼尾巴的那根线一路延伸 → 另一头系着一条暗淡的玫瑰色鱼，蜷着；两条鱼化成双鱼座的星，读数 Alrescha =「绳子」。
   "理解一个人的难处，也可以告诉他：你受伤了" → 光鱼第一次掉头，顺着绳游回去，玫瑰色的鱼亮起来，两条鱼绕在一起（高潮，全片最亮）。
8. 尾声：两条鱼在黑暗里并排；"那我呢？""我今天，开心吗？" → 片名《那我呢》 PISCES。

**声音**（无配音无配乐，只有音效，~50 个 cue）：水下底噪、墨滴入水、墨团翻滚、鱼摆尾的 whoosh、话沉下的闷响 + 气泡、泪滴 ding、
人群 murmur → 抽空到只剩心跳、海浪 + 风、日期翻页 tick、灯落水的水滴声 + ding（五声音阶）、倒影破水 splash、高潮 swell + shimmer、片名 boom。
