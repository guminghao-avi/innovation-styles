# 自渡（像素风）

> 历史创作示例：保留原有立意和结构。以下未附出处的事实、数字或流行趋势，制作新片前需重新核实；星座性格仅作娱乐表达。

**一句话核心**：「谁能救我？」—— 这道题的选项一个个变灰，最后剩下那个一直锁着的，是「我自己」。
落点：没有船会来，可桨一直在你手里；自渡不是孤军奋战 —— 每座孤岛上都有人在造船，灯连起来，就是一条航道。

**语境（查证）**：2026 年 9~10 月流行词「自渡」：指靠自己走出困境、完成心理上的自我救赎。佛教有"渡人自渡"之说，2023 年也流行过。
走红原因：开学 / 秋招 / 裁员焦虑集中、求助通道收窄、年轻人从"等救援"转向"自己动手"。金句："不等救生圈了，自己造船。"
注意：自渡 ≠ 孤军奋战 —— 该借的力照借。

**视觉母题**：一盏提灯（暖金）+ 一个游戏选择菜单。片头菜单里锁着的「？？？」，到结尾解锁成「我自己」。

**世界**：夜海上的像素孤岛（480×270 最近邻放大），蓝紫夜、像素月亮、远处路过不回头的船灯；
HUD 左上角一直挂着：状态（等待救援 → 准备出发 → 航行中 → 靠岸）、已等待天数、信号 发出/回应。

**结构（成片 3:04.8）**
1. 片头 0~30s（5 倍像素远景）：菜单「谁能救我？」选项变灰、「？？？」上锁 → 孤岛等船、天数飞涨、信号 ×415 / 回应 0 → 片名「自渡」→ 捞到第一块木板。
2. 捡木板 30~64s（8 倍近景）：信沉进海里（未回复）→ 改一版再投，变成木板；年度目标 → 一天一格；学东西、睡一觉；冲刺攒到 12/12。
3. 下水就沉 64~88s：合成木筏 Lv.1 → 下水 → 裂开、落水、「船体损毁」→ 游回来、捞回木板 → 钉牢，Lv.2 → 圆形遮罩出海。
4. 暴雨 88~117s（6 倍中景）：「焦虑」「委屈」「自我怀疑」……砸在木筏上，积水 87% → 流过去，积水归零 → 接着划。
5. 夜航 117~155s（5 倍远景）：别的岛上也亮着灯 → 有人在造船 → 邻居划过来抛绳 →「能帮我一下吗？」「来了！」回应 0 → 1 → 灯连成航道 → 天亮。
6. 落点 155~185s：黎明里另一座孤岛上的"你" → 菜单再出现，锁裂开：「我自己」→ 站起来、灯亮 → 12 倍特写：桨在手里（状态：自渡中）→ 一排木筏沿航道划向太阳 → 片名 + 献词 → 淡出。

**颜色语义**：暖金 = 自己的光 / 提灯；冷白蓝 = 等待、别人的船灯；红 = 拒绝、变灰的选项；黎明橙 = 抵达。
