# 风格 14：弥散渐变 · 玻璃拟态（Aurora · Glassmorphism）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **极光渐变打底 · 磨砂玻璃浮在上面 · 透光、折射、带点色散 · 科技产品发布片**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 10 种（作品：虚构助手 Aurora 的发布片「思考，自有光」；标签 WebGL 着色器、CSS 毛玻璃）。
> 工具：`@styles/glass`；示例：`projects/示例_弥散渐变玻璃拟态/`（三块磨砂玻璃浮起：聆听波形 / 回复 / 专注开关 → 收起，光球亮起，字标 Aurora）。

## 一、一句话认出它
深紫蓝的底上几团大色块（紫、蓝、粉、青）缓慢流动；几块圆角玻璃浮在上面，里面看得到后面的颜色但被磨砂、折射过，边缘一道亮边、下面一圈影子；玻璃上是极简的 UI 文字和控件。

## 二、什么题目用它
AI / 科技产品、App 功能介绍、未来感、"安静的高级感"。

## 三、长什么样
- 底：`(.025,.02,.09)` 深紫 + 4 团高斯色块（紫 `.42,.2,.95`、蓝 `.1,.45,1`、粉 `.95,.3,.7`、青 `.15,.85,.95`）被扭曲噪声推着慢慢流；一颗白色光球。
- 玻璃：圆角 34px；透镜折射（越靠边越弯）+ RGB 三通道错开（色散）+ 提亮 `col×.85 + (.13,.12,.2)` + 磨砂颗粒 + 左上亮边 + 右下内阴影 + 下方投影。
- 内容：Grotesk 细体英文 + 思源黑体 Regular；控件（开关、滑条、波形条）用纯白 / 浅蓝 `#9fd8ff`；字幕细体白字。
- 运动：玻璃 spring 慢慢浮起（freq 1.6、阻尼 .7，不弹）；内容晚 0.3 秒淡入；退场下沉 + 收小。

## 四、技术实现方案
**玻璃不用 CSS `backdrop-filter`（软件渲染下大面积模糊很慢，而且做不出折射色散）：在同一个着色器里，玻璃区域直接"重新采样一次背景"。**
```tsx
import { AURORA, GL, rectStyle } from '@styles/glass';
<Shader frag={GLSL.noise + GLSL.color + AURORA} scale={.5} u={{ uC0: [x, y, w, h], uC1, uC2, uC3, uRad: 34, uGlow, uOrb: [x, y], uExpo: .62 }} />
<div style={{ ...rectStyle(c0), padding: ... }}>玻璃上的字、控件（DOM）</div>   // 同一个矩形
```
- 着色器里：`sdRoundRect` 判断在不在玻璃里；在的话 `aurora(p - off)` 采样三次（R/G/B 偏移 ×1.08 / ×1 / ×.92）= 折射 + 色散；`off = 方向 × (1 - 离边距离/60) × 26px`。
- 背景本身是低频的（大高斯色块），所以玻璃里不需要真模糊，"磨砂"感来自提亮 + 颗粒 + 折射；需要更模糊时把玻璃区的 `aurora()` 改用更低频参数。
- 玻璃的位置 / 大小每帧从 TS 传进去（spring 动画），DOM 内容用同一个矩形 —— 两层严丝合缝。
- 曝光要低（.6 左右）：ACES 下背景很容易发白，失去"深色底上的光"。
- `post.json`：`{ "grain": 3, "vignette": 0.2, "bloom": 0.25, "bloomThreshold": 0.55 }`。

## 五、声音
很轻的电子提示音：卡片浮起 `swell` 很短、开关 `tick`、滑条 `whir` 短、字标出现 `shimmer` + `ding`（高、干净）。

## 六、坑
- 用 CSS `backdrop-filter: blur(40px)` 整屏玻璃：大面积模糊可能增加渲染负载，先做对照测试。
- 背景太亮：玻璃看不出来（玻璃靠"比背景亮一点 + 亮边"才成立）。
- 玻璃上放大字号粗体 = 不高级；细体、留白多。
