# 风格 18：液态流动（Liquid Motion · SDF 融球）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **粘连、拉丝、融合、弹跳 · 光泽饱满得像能捏起来 · 一滴落下，溅成字标**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 14 种（作品：虚构汽水 drop.「万物始于一滴」；标签 WebGL、SDF 融球）。
> 工具：`@styles/liquid`；示例：`projects/示例_液态流动/`（一滴果冻落下 → 溅成水珠、拉丝被吸回 → 长成 "drop" 四个字母、晃两下 → 倒影）。

## 一、一句话认出它
深紫底上，橙到粉渐变的"果冻"液体：一滴落下、溅开，水珠之间拉着丝、碰到就融成一团，最后长成字母；表面有饱满的高光、边缘暗一圈、内部透着光，下面一面暗色的倒影。

## 二、什么题目用它
饮料 / 美妆 / 食品品牌、"开始 / 起源"、柔软 / 流动 / 变化的概念、字标开场。

## 三、长什么样
- 底：深紫径向 `(.16,.04,.2) → (.05,.01,.08)`；液体：橙 `(1,.42,.12)` → 洋红 `(.95,.12,.55)`（按 x 渐变）。
- 质感：圆顶法线（越往中间越"高"）→ 漫反射 + 强镜面高光 + 边缘暗圈 + 厚的地方更饱和（透光）+ 外发光。
- 运动：下落加速（`drop²`）、溅开（抛物线）、被吸回（`smoothstep` 往目标点插值）、字母成形后果冻般晃（按 y 横向正弦偏移，指数衰减）。
- 倒影：基线以下镜像、压到 28% 亮度、带波纹。
- 字：衬线细体中文 tagline 宽字距；字幕粗黑体 + 粉色外发光。

## 四、技术实现方案
**一个 2D 距离场着色器（`LIQUID`，scale .5）：所有液体 = 圆 / 胶囊 / 圆环 / 圆弧的 SDF，用 `smin`（平滑并集）合起来 —— 粘连和拉丝是 smin 自动产生的。**
- 字母用基本形拼：o = 圆环；d = 圆环 + 右边竖胶囊；r = 竖胶囊 + 上半圆弧；p = 圆环 + 左边向下的竖胶囊；线宽 `w = 26 × 成形进度`（从无到有"长"出来）。
- 水珠：7 颗，沿抛物线飞出，`mix(抛物线位置, 目标点, smoothstep(.25,.9,t))` 被吸回，半径随时间缩小；`smin(d, 水珠, 38)` 让它们和字母之间拉丝。
- 着色：距离场当高度场 —— `h = clamp(-d/30, 0, 1)`，法线 = 梯度（四次采样）× (1-h) + z 分量；高光 `pow(…, 60)`。
- 倒影：`p.y > 基线` 时用 `(x + 波纹, 2·基线 - y)` 再算一次场景。基线要低于所有字母的下伸部分（p 的竖笔），否则字母会"接"到自己的倒影。
- 参数从 TS 传：`uDrop`（下落进度）、`uSplash`（溅开后归一化时间）、`uForm`（字母成形）、`uWob`（晃动幅度）。
- 本示例是二维距离场的视觉模拟。三维 SDF 可另加光线步进、折射与菲涅尔；真实流体运动还需模拟，不能只加光照就视为实现。按 [工具选择](工具选择.md) 选择路线。
- `post.json`：`{ "grain": 3, "vignette": 0.3, "bloom": 0.3, "bloomThreshold": 0.6 }`。

## 五、声音
水滴 `bubbles`（落下一颗）、溅开 `splash` 小、融合的黏声（`bubbles` 低沉、慢）、字标成形 `pop` + `shimmer`。

## 六、坑
- 用硬 `min` 合并：没有拉丝、像贴图。smin 的 k 30~40px 正好。
- 倒影基线太高：p 的下伸笔画碰到倒影。
- 法线只用梯度不加高度：表面平、没有"饱满"感。
