# 风格 19：综艺花字（Variety Captions）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **多层描边、弹跳、表情贴 · 专门放大情绪 · 三只猫、三种心情、三套花字**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 15 种（作品 喵呜日记 EP.07；标签 DOM·SVG、弹簧动画、9:16 竖屏）。
> 工具：`@styles/variety`；示例：`projects/示例_综艺花字/`（一只猫：震惊 → 耍赖 → 开心，三套花字 + 表情贴纸 + 综艺急推）。

## 一、一句话认出它
综艺节目 / 短视频的字：大、粗、多层描边（外白、内深、渐变填色），出来时弹一下、抖一下或者砸下来；旁边配汗滴、怒气符号、问号、闪光、爱心这些贴纸；每次花字出来画面猛推一下。

## 二、什么题目用它
萌宠、日常 vlog 式的叙事、搞笑、情绪化的小故事；竖屏短视频（9:16）是它的主场，横屏也成立。**它也可以叠加在其他风格上**当"情绪放大器"。

## 三、长什么样
- 三套预设（`PRESETS`）：
  - 震惊 shock：黄 → 橙渐变 + 黑内描 16 + 白外描 34，思源黑体 900 210px，斜 -8°，**抖**；
  - 耍赖 pout：粉渐变 + 深玫红内描 + 白外描，得意黑 140px，**逐字波浪弹跳**；
  - 开心 yay：彩虹横向渐变 + 深紫内描 + 白外描，得意黑 220px，**从大砸下来**。
- 贴纸（SVG 画，不依赖 emoji 字体）：汗滴、怒气（四段红弧）、问号、闪光星、爱心；弹入 + 上下浮 + 轻摇。
- 画面：每次花字出现，整个画面急推 8%（`exp(-6t)` 衰减）；背景色跟情绪换（震惊黄 + 集中线、耍赖粉、开心青绿）。
- 普通字幕：白字 + 10px 深紫描边（`paint-order: stroke fill`），在下方。

## 四、技术实现方案
**DOM：同一段文字叠三层 —— 外描边层（`-webkit-text-stroke` 很宽的白）→ 内描边层（较窄的深色）→ 填色层（渐变 `background-clip: text`）；每个字是一个 `inline-block`，三层的逐字变换完全一致。**
```tsx
import { Huazi, Sticker, PRESETS } from '@styles/variety';
<Huazi text="震惊！" t={t - at} st={PRESETS.shock} anim="shake" x={520} y={260} rot={-8} out={...} />
<Sticker kind="sweat" t={t - at} x={1300} y={380} />
```
- `anim`：`pop`（spring 整体弹出）、`wave`（每字 `sin(t·9 - i·.8)` 上下 + 依次弹入）、`shake`（随机抖、指数衰减）、`stamp`（2.2 倍砸到 1 倍）。
- 描边一定要"外宽内窄"两层：只用一层 text-stroke 会吃掉字的笔画（stroke 是居中描的）。
- 竖屏 9:16：`src/kit/time.ts` 的 W/H 改成 1080×1920（或单独一个 Composition），花字放画面上 1/3 和下 1/4。
- 性能：DOM 文字 + SVG；先测多字与滤镜叠加的代表镜头。
- `post.json`：`{ "grain": 2, "vignette": 0.15, "bloom": 0.05 }`。

## 五、声音
综艺音效是灵魂：震惊 = `impact` 小 + 一声"咚"（`boom` 高一点）+ `glitch`；耍赖 = `pop` 连发（音高起伏）；开心 = `jingle` + `shimmer`；急推 `whoosh` 很短。（这一种风格音效可以比其他风格多一点，但仍然只跟花字出场。）

## 六、坑
- 一层描边：字被描边吃细、发糊。
- 渐变填色层用 `color: transparent` 时，外描边层必须是单独的层，不然描边也变透明。
- 花字太小（< 120px）就失去综艺感；但同屏最多两条花字。
