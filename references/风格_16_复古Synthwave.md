# 风格 16：复古 Synthwave（80s Synthwave · VHS）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **80 年代的霓虹、网格和条纹落日 · 再加一层录像带噪点 · 按下播放，跑车冲向地平线**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 12 种（作品 NEON DRIVE「霓虹夜驰 1986」；标签 WebGL、VHS 后期）。
> 工具：`@styles/synth`；示例：`projects/示例_复古Synthwave/`（PLAY ▶ 带一下跟踪错位 → 落日、线框山、霓虹网格向前滚、棕榈树 → 尾灯冲向地平线 → 铬字 NEON DRIVE + 霓虹手写 Midnight）。

## 一、一句话认出它
紫红色的天，一轮上黄下粉、下半截被横条切开的大太阳，霓虹粉描边的线框山，地面是向前滚动的透视网格；画面有扫描线、色散、偶尔一条横向错位（录像带跟踪不良），左上角 "PLAY ▶"。

## 二、什么题目用它
怀旧、复古、夜晚 / 速度 / 自由、80 年代文化、游戏 / 音乐 / 汽车；情绪浓、视觉冲击强。

## 三、长什么样
- 天：`(.03,.005,.08)` → `(.42,.03,.36)` → 地平线附近偏橙粉；星点。
- 太阳：中心在地平线上 190px、半径 250；上 `#ffc71f` → 下 `#ff1473`，下半部横条缺口越往下越宽。
- 山：低多边形山脊（分段线性），暗紫填充 + 霓虹粉描边 + 竖向分段线。
- 地面：透视网格（`z = k / (y - 地平线)`），纵线固定、横线向前滚（速度可加快）；远处淡出防摩尔纹；地平线一道亮。
- 字：铬字（白 → 天蓝 → 深紫分界 → 粉 → 白 的竖向渐变 `background-clip: text` + 白描边 + 粉色辉光 + 深紫硬投影）+ 霓虹手写体（粉色多层 text-shadow）。
- VHS：扫描线（DOM 2px 条纹）、色散（post `ca: 3`）、颗粒 9、跟踪错位带（着色器里一条横带整体右移 + 噪声）、"PLAY ▶" / 日期 / 计时 等宽屏显。

## 四、技术实现方案
**一个全屏着色器（`SYNTH`，scale .5）画天、太阳、山、地面和错位带；Canvas2D 画棕榈树剪影和车；DOM 放字和屏显。**
```tsx
import { SYNTH, SW, palm } from '@styles/synth';
<Shader frag={GLSL.noise + GLSL.color + SYNTH} scale={.5} u={{ uSpeed, uHz: 600, uSun: 0, uTrack: 跟踪带的y（-1 = 没有）, uExpo: .8 }} />
<Canvas2D draw={g => palm(g, x, y, h, sway)} />
```
- 地面网格：`z = 260 / dy`，`wx = (x - 960) / dy × 2.6`；`fract(wx)`、`fract(z - t·speed)` 离 .5 的距离 → 线；线宽随 z 变、远处 `smoothstep(80, 12, z)` 淡出。
- 太阳横条：`v > .45` 后 `step(.3 + (v - .45)×1.4, fract(y / 26))`（越往下缺口越宽）。
- 棕榈树：二次曲线锥形树干 + 7 片弯刀形叶子（两条二次曲线围成），按 z 往两侧退 = 向前开的感觉。
- 跟踪错位：`band = smoothstep(18, 0, |y - uTrack|)`，`px.x += band × (24 + 30·hash)`；开场 0.4 秒 + 中间随机一次就够。
- `post.json`：`{ "grain": 9, "vignette": 0.4, "bloom": 0.4, "bloomThreshold": 0.45, "bloomRadius": 30, "ca": 3, "eq": "saturation=1.15" }`。

## 五、声音
录像机机械声（`clunk` + 磁带 `tape`）、跟踪错位 `glitch`、引擎 `riser` 低沉长、冲向地平线 `whoosh` + `impact`；（用户要配乐时才用 synth 和弦 + 鼓机）。

## 六、坑
- 曝光太高：整片洗白成粉紫一团，太阳失去渐变；曝光 .8、天要暗。
- 太阳太低：条纹那一半藏在山后面看不到。
- 网格远处不淡出：摩尔纹闪烁。
