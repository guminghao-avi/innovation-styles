# 风格 08：线条动画（Line Art · 一笔画）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **线就是全部画面 · 留白一样重要 · 一根金线全程不离纸 · 从一粒种子画到整座城**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 04 种（作品 ATELIER LINEA「一笔画」）。
> 工具：`@styles/line`；示例：`projects/示例_线条动画/`（金线沿地面走：种子 → 芽 → 小房子 → 一排楼 → 远山 → 太阳，镜头跟笔尖，最后拉远）。

## 一、一句话认出它
深蓝夜色的纸上只有一根发光的金线，它一直在"画"——画出一样东西后不抬笔，接着去画下一样；镜头跟着笔尖，最后拉远，一整幅画是一笔连下来的。

## 二、什么题目用它
品牌故事、成长 / 历程（从小到大）、城市 / 建筑 / 工艺、"一以贯之"的主题；高级、克制。

## 三、长什么样
- 底：深海军蓝径向渐变 `#16213a → #0d1424`；线：金 `#e9c46a`，笔尖亮 `#fff2c4`。
- 线宽 3px + 一层 7px 模糊发光（SVG `feGaussianBlur` 6~7）；笔尖一颗亮点 + 光晕。
- 画面里除了线，只有字幕和片名（Garamond 宽字距英文 + 宋体小字）。
- 运动：笔尖匀速偏缓（`E.inOut` 轻微）；镜头横向跟笔尖、**纵向固定**，结尾 `E.film` 拉远看全貌。

## 四、技术实现方案
**整幅画 = 一条连续的 SVG path；用 `stroke-dasharray / stroke-dashoffset` 按进度画出来。**
```ts
import { Pen, LINE } from '@styles/line';
const pen = new Pen().move(-200, G).line(260, G, 8)
  .curve(cx, cy, x, y).leaf(70, -2.5).arc(cx, cy, r, a0, a1)   // 连续落笔，只 move 一次
  .line(560, G - 170).line(650, G - 250) ...;
const D = pen.d, LEN = pen.len;                                 // 模块加载时算一次
<path d={D} strokeDasharray={LEN} strokeDashoffset={LEN * (1 - p)} />
const [tx, ty] = pen.at(LEN * p);                               // 笔尖位置（二分查找累计长度表）
```
- `Pen` 记录所有点和累计长度，`at(L)` 二分查找 → 比 `getPointAtLength` 快（长路径每帧调用不卡）。
- 也可以用 `@remotion/paths` 的 `evolvePath(p, d)`（返回 dasharray/dashoffset）和 `getPointAtLength`，适合手写的 SVG path 字符串。
- 镜头：`<g transform="translate(...) scale(s)">`，笔尖停在屏幕 58% 处；线宽除以缩放（`3.2 / s`）保持粗细恒定。
- `post.json`：`{ "grain": 3, "vignette": 0.3, "bloom": 0.25, "bloomThreshold": 0.5 }`（让金线发光）。

## 五、声音
笔在纸上的细声（`scribble`，很轻、长）；画完一样东西一个轻的 `ding`；结尾拉远 `swell`。

## 六、坑
- 镜头纵向也跟笔尖 → 画到高楼时画面上下乱跳；纵向固定。
- 路径里有 move（抬笔）→ dasharray 会在断点处出问题，也违背"一笔画"。
- 线太细太暗在 1080p 上看不清；3px + 发光层。
