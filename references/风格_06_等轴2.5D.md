# 风格 06：等轴 2.5D（Isometric）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **没有透视的等轴俯视 · 像桌上的微缩模型 · 一格一格长出来 · 踩着马林巴的节拍 · 粉紫 / 薄荷的柔和配色**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 02 种（作品 ISOPOLIS「让城市自己生长」）。
> 工具：`@styles/iso`；示例：`projects/示例_等轴2.5D/`（9×9 地台按对角线铺开 → 楼、树、风车按拍长出来 → 地面上的字 ISOPOLIS）。

## 一、一句话认出它
一块方形的"桌面地台"斜 45° 摆着，所有东西都是小方块：楼、树、风车，三个面三种明度（顶最亮、左中、右暗），没有透视（远近一样大），像积木城市。

## 二、什么题目用它
城市 / 系统 / 产品架构 / 增长（"从 0 到 1 长出来"）、流程（物流、数据流动）、游戏化的说明。数据可以直接变成楼高。

## 三、长什么样
- 投影：等轴（x、z 轴各偏 30°），1 格 = 70~90px。
- 每个方块三面：顶色 `col`、左前面 `col×0.86`、右前面 `col×0.74`，顶面前沿一道白色亮边（微缩模型的倒角）。
- 配色：底 `#e9e5f8`、地台 `#d8d1f1`、白楼 `#f6f4ff`、薄荷楼 `#8fe0c0`、窗 蓝 `#6c7fe0` / 亮 `#fff6c8`、字 `#2b2d6e`。
- 运动：元素按拍"长出来"（`pop` = spring 过冲 0→1.12→1）；地砖按 (x+z) 对角线一波铺开；镜头只做很慢的推拉（不转，转了要重排序）。
- 字：地面上的字用 canvas 变换"平铺"在等轴平面上（`groundText`）；字幕用圆角胶囊白底黑体。

## 四、技术实现方案
**Canvas2D 自己做正交投影 + 画家算法**（原文将参考标注为 Three.js 正交相机；当前示例采用 Canvas 投影）。
```ts
import { ISO, isoP, box, tree, groundText, pop, beatAt } from '@styles/iso';
const c = { cx: 960, cy: 250, s: 74 };                    // 镜头：原点位置 + 每格像素
isoP(c, x, y, z) → [sx, sy]                                // sx = cx + (x - z)·cos30·s，sy = cy + (x + z)·0.5·s - y·s
box(g, c, x, y, z, w, h, d, col)                           // 画三个可见面
```
- **画家算法**：先把所有地砖（平的）画完 → 地面上的字 → 再把立着的东西按 `x + z` 从小到大排序画（远的先画）。字要在楼之前画，才会被前面的楼挡住。
- 生长：每个物体有一个出场拍 `beatAt(i, 240)`（八分音符），高度 × `pop(t - at)`；窗户晚 0.4 秒亮。
- 想要真 3D（转镜头、阴影）：用 `@remotion/three` 接入 Three.js 的 `OrthographicCamera`（position 在 (1,1,1) 方向、lookAt 原点），`InstancedMesh` 画方块；实例数量和阴影会影响耗时，先测短片。
- `post.json`：`{ "grain": 2, "vignette": 0.15, "bloom": 0.05 }`（干净的色块，别加太多颗粒）。

## 五、声音
马林巴（`notes inst:marimba`，五声音阶）每长出一个东西一个音 —— 这是"节拍感"的来源（用户要求不要配乐时，把它当音效：每个落地一个短音，整条 30~45 个以内）；风车 `whir` 很轻。

## 六、坑
- 不排序直接画：后面的楼会盖住前面的。
- 地面字最后画：会"浮"在楼上面。
- 地台放太低会和字幕打架；地台中心放在画面上 1/3。
- 镜头转动会打乱 `x+z` 的排序规则 —— 要转就上 Three.js。
