# 风格 15：几何构成 · 包豪斯（Geometric · Bauhaus）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **圆、方、三角 · 红、黄、蓝、黑 · 严格的网格、严格的节拍 · 一张海报用 20 拍把自己搭起来**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 11 种（作品「二十拍构成 KONSTRUKTION」；标签 120px 网格、120 BPM）。
> 工具：`@styles/bauhaus`；示例：`projects/示例_几何构成包豪斯/`。

## 一、一句话认出它
米白纸上一张竖版海报：淡淡的网格和裁切线；每一拍"砰"地落下一个元素——大红圆、黑竖条、蓝半圆、黄三角、竖排的 BAUHAUS——落下就停住，不弹；右边一个节拍计数器在走。

## 二、什么题目用它
设计 / 艺术史、"结构 / 秩序 / 拆解"、品牌视觉系统的展示、把一个复杂东西"一块块搭起来"的讲法；理性、有力。

## 三、长什么样
- 纸 `#f1e9da`、红 `#d8322a`、黄 `#f2b51d`、蓝 `#1f4fa3`、黑 `#151515`；网格线 8% 黑；四角十字裁切线。
- 一切对齐 120px 网格（`U = 120`）：位置、尺寸都是 U 的倍数或 0.25U。
- 节拍：120 BPM = 0.5 秒一拍；第 i 个元素在 `beat(i)` 出场，`E.snap` 0.28 秒内落定，**不过冲**（包豪斯是严格，不是可爱）。
- 进场方式只用几种：从 0 缩放出现、从边缘滑入、沿一个方向"长"出来（条、线）、描边画一圈（圆环）。
- 字：Grotesk 粗体大写竖排、等宽小字（FORM · FARBE · FUNKTION、BOGEN 09…）；中文黑体 900。

## 四、技术实现方案
**SVG（DOM），坐标全部写成网格单位；一个元素 = 一行，按拍号排。**
```tsx
import { BH, U, beat, hit, Grid } from '@styles/bauhaus';
const b = (i: number) => hit(t, beat(i, .15));               // 第 i 拍的落定进度 0..1
<Grid x={X} y={Y} w={6 * U} h={8 * U} a={b(0)} />
<circle cx={X + 2 * U} cy={Y + 5 * U} r={1.9 * U * b(1)} fill={BH.red} />
<rect x={X + 3 * U} y={Y} width={U * .5} height={PH * b(2)} fill={BH.black} />
```
- 海报内容放在 `<clipPath>` 里（溢出部分被海报边裁掉，像印刷品）；竖排字用 `rotate(-90)` + `clip-path: inset()` 逐渐露出。
- 画圆环：`strokeDasharray = 周长 × 进度`。
- 节拍计数器（4×5 方块随拍亮起）把"严格的节奏"可视化。
- 声音一定要对拍：每拍一个 `tick` / 木鱼声；sound.json 的时间直接用 `beat(i)`。
- 性能：纯 SVG；先测高密度构图和转场。
- `post.json`：`{ "grain": 4, "vignette": 0.18, "bloom": 0 }`（印刷品颗粒感）。

## 五、声音
节拍器式：每拍一个短 `tick`（低音一点，像木块），每 4 拍重音；海报完成一个 `impact` 小 + `ding`。

## 六、坑
- 元素带回弹 = 失去包豪斯的"严格"；用 snap 停住。
- 不贴网格的随手摆放会马上显得乱。
- 小字溢出海报：等宽字宽度 ≈ 字号 × 0.6 × 字数，算一下再摆。
