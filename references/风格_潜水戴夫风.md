# 风格二：潜水戴夫风（明亮海底 · 像素角色 × 平滑 3D 感环境 · 休闲游戏 UI）

> **蓝洞里的光柱和珊瑚 · 胖乎乎的像素潜水员 · 粗描边圆角 UI · GET! 图鉴卡 · 对话框就是字幕 · 轻松、好笑、有梗**
> 灵感：游戏《潜水员戴夫 DAVE THE DIVER》（MINTROCKET）的审美 —— 官方说法是"2D 像素和 3D 美术结合"：角色是像素，海底环境是平滑的 3D。
> 这里只借审美，角色、界面全是自己画的（不用游戏素材、不用戴夫本人形象）。
> 工具：`@styles/diver`；最小示例：`projects/示例_潜水戴夫风/`（21 秒：水面登场卡 → 下潜，红鱼褪成灰 → 手电照回红色 → GET! + 金币）。

## 一、一句话认出它
明亮的青蓝海水、斜着打下来的光柱、两侧礁壁和海草；一个圆滚滚的像素潜水员在中间游，左上角氧气条、右边深度计，
抓到东西就"GET!"弹出一张图鉴卡，下面是带头像的对话框在讲话。**和自渡风的区别：亮、饱和、热闹、好笑；环境是平滑的（不像素化），只有角色和道具是像素。**

## 二、什么题目用它
- **轻松的知识科普 / 冷知识 / 反差梗**：海洋、动物、物理现象、生活里的"为什么"（为什么红鱼在深海会隐身、为什么鱼不会冻住……）。
- 能翻译成**"一个角色去完成一个任务"**：下潜找东西、收集、经营、打怪 —— 每个知识点 = 一个关卡 / 一张图鉴卡。
- 想要高信息密度 + 好笑 + 节奏快。
- 不适合：沉重、抒情、孤独的题（→ 自渡风 / 写实电影感）。

## 三、长什么样
**1. 两种质感叠在一起（这是灵魂）**
- **环境 = 平滑、全分辨率、像 3D 渲染**：`OCEAN` 着色器 —— 按深度变色（浅水青 `.30,.86,.90` → 中层蓝 → 深海墨蓝）、斜光柱（越深越淡）、
  焦散、三层礁壁剪影（越远越被水色吞掉、视差越小）、海床（沙 + 焦散）、水面（上面是天和太阳）。**不像素化、不用 ACES**（明快的风格化海，颜色直接是 sRGB）。
- **角色 / 鱼 / 海草 / 珊瑚 / 气泡 = 像素**：`Grid` 格子画板拼形状（椭圆、矩形、三角、线），最后 `outline(INK)` 自动描 1px 深色外轮廓；
  画在 1/5 分辨率画布上最近邻放大（潜水员约 34×22 像素 → 屏幕上 ~170px）。像素角色比自渡风大一号、描边更粗、颜色更饱和。
- 光层（全分辨率 `lighter`）：海雪（往下飘的小白点）、手电光锥、闪光。

**2. UI：休闲手游式**
- 面板：深海蓝渐变底 + **6px 墨色描边** + 4px 浅青内边 + **向下的硬投影**（像能按下去的按钮），圆角 12~18。
- 颜色：黄 `#ffd23f`（主强调、名牌、深度指针、GET!）、珊瑚红 `#ff6b4a`（重点词、NEW、登场卡）、青 `#3ee6d6`（氧气）、墨色 `#13203a`（所有描边）。
- 字体：数字和标签用像素字 `F.pixel`（12 的倍数）；大字、名牌、对话用得意黑 `F.fun`（圆润、有喜感）。
- 组件（`@styles/diver`）：
  - `O2Bar` 左上角氧气条（气瓶图标 + 16 格 + 数值，<25% 变红闪）—— 给"时间压力"。
  - `DepthGauge` 右侧深度计（刻度随深度滚动，黄色指针 "12.4m"）—— 深度就是进度条。
  - `Dialog` **字幕 = 对话框**：奶白底 + 头像 + 黄色名牌（旁白 / 角色名）+ 打字机 + 句末 ▼ 闪；`**词**` 珊瑚红、`「词」` 黄。
  - `CatchCard` "GET!" 图鉴卡：旋转放射光 + 描边大字 GET!（歪 4°）+ 卡片里的像素图 + 名字 + 三颗星依次弹出 + NEW 角标。**一个知识点 = 一张卡**。
  - `CoinPop` "+120" 金币飘字；`Exclaim` 头顶 "!" 气泡；`IntroCard` 角色登场卡（斜切色带从左扫进来 + 大名字 + 一句外号，定格感）。
- 动效：全部弹性（`pop()` = spring 带一次回弹），入场"啵"地放大；对话框只在新段落弹一次。

**3. 颜色就是语义**
| 用途 | 颜色 |
|---|---|
| 海（浅 → 深） | `#4cdbe6` → `#127fc7` → `#083380` → `#021234`（着色器里按米算） |
| 主角 | 潜水服蓝 `#2f56a8` + 黄色气瓶 / 脚蹼 `#ffd23f` |
| 目标 / 重点 | 珊瑚红 `#ff6b4a`、鱼红 `#e8463c` |
| 奖励 | 黄 `#ffd23f`（GET!、金币、星星） |
| 描边 | 墨 `#13203a`（UI 和像素精灵统一） |
| 海草 / 珊瑚 | `#2f9e6a` `#3bb27a` / `#ff7a8a` `#ffb347` `#c86bff` |

**4. 叙事：把知识做成"关卡"**
- 开头登场卡介绍角色 + 今天的任务（订单 / 委托）—— 第 0~3 秒就有画面事件（扑通下水）+ 第一句对话。
- 深度 / 氧气 / 金币这些数值推着走；知识点变成**游戏机制**（示例：越深红色越灰 = "海水先吃掉红光"；手电一照，红色回来）。
- 每解决一个问题弹一张图鉴卡（名字 + 一行冷知识），结尾结算（金币、星级）。可以加经营段落（餐厅、订单、顾客头顶的气泡）。

## 四、怎么做
```tsx
import { OCEAN, Grid, diver, fish, kelp, coral, INK, O2Bar, DepthGauge, Dialog, CatchCard, CoinPop, IntroCard, Exclaim, GridSVG, Panel, D } from '@styles/diver';
<Shader frag={GLSL.noise + GLSL.color + OCEAN} scale={.5} u={{ uDepth, uPPM: 40, uFloor: 30, uCamX }} />   // 环境（平滑）
<Canvas2D scale={.2} style={{ imageRendering: 'pixelated' }} draw={...} />                               // 像素角色
<Canvas2D draw={...} />                                                                                    // 光层（lighter）
```
- **世界坐标用米**：纵向 = 深度（屏幕中线 = `uDepth`），横向 = `uCamX`；像素层换算 `px = 192 + (x - camX) * PPM / 5`。着色器、像素层、光层三层用同一套换算，严丝合缝。
- 镜头跟着角色走（`camAt = 角色位置 + 偏移`），下潜用 `E.film`；开场贴着水面（上半屏天空、下半屏海）。
- 新精灵：`const s = new Grid(); s.ellipse(...).rect(...).tri(...); s.outline(INK); s.draw(g, x, y, flip)`；
  在 UI 里显示同一个精灵：`<GridSVG grid={s} s={7} />`。帧动画用 `Math.floor(t * 5~7) % 2`（脚蹼、尾巴两帧摆）。
- 颜色随深度变（示例 `redLoss`）：越深红色越往灰蓝靠 —— 知识点直接长在画面上。
- `post.json`：`{ "grain": 2, "vignette": 0.15, "bloom": 0.14, "bloomThreshold": 0.7 }`（明亮画面 bloom 要克制，不然整片发白）。

## 五、声音
水下底噪 `underwater`（-24）+ 气泡 `bubbles` + 明快的游戏提示音：登场 `whoosh`、下潜 `whoosh dir -1`、开关 `clunk`、"!" `pop`、
**GET! = `jingle`（marimba，C5 E5 G5 C6 E6 上行）**、NEW `pop`、金币 `coin`、入水 `splash`。只配关键节点。

## 六、踩过的坑
- 礁壁条件写反（`smoothstep` 两个边界顺序）会把整个画面中间盖成一块暗石头 —— 先单独渲着色器看一眼。
- 焦散网格太强 = 像渔网：礁石上 ≤ .08、空水里 ≤ .035。
- 像素层用 1/4 分辨率时潜水员太小、没有"萌"感；1/5 正好。
- 气泡画成方框像 UI 图标：用十字形 5×5（四边 + 中间 3×3 亮 + 左上一点高光）。
- 金币飘字别压在 NEW 角标上；图鉴卡出现时字幕还在，卡片放在中线偏右上，避开下方对话框。
