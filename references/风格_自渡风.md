# 风格一：自渡风（暗夜像素叙事）

> **蓝紫夜海 · 像素小人 · 硬像素叠软光 · 一直挂着的 HUD · 把概念做成游戏机制**
> 来源：《自渡》（3:04，`projects/参考_自渡/` 是完整源码）和更早的"像素风"样片。
> 工具：`@styles/pixel`；最小示例：`projects/示例_自渡风/`（20 秒，菜单 → iris → 夜海孤岛 → HUD → 获得物品 → 片名）。

## 一、一句话认出它
深夜的海上一座小礁石，一个围着金色围巾的像素小人提着灯坐着；左上角挂着状态面板（等待天数、信号 发出/回应 0），
远处的船灯路过、不回头。情绪是**安静的孤独 + 一点点倔**。画面暗、颜色少，唯一的暖色是那盏灯。

## 二、什么题目用它
- **困境 / 自我救赎 / 等待 / 成长**这类有"处境"的题目：自渡、躺平与站起来、孤独、坚持、重启人生……
- 题目能翻译成**一个人在一个世界里做一件事**（等船 → 捡木板 → 造筏 → 下水沉了 → 再造 → 出海 → 遇到别的灯）。
- 想要"独立游戏过场动画"的质感：克制、有代入感、能截图。
- 不适合：纯知识讲解（数据多、需要图表 → 用写实电影感或潜水戴夫风）、需要大量欢乐气氛的题（→ 潜水戴夫风 / 纸艺手绘）。

## 三、长什么样
**1. 画面：低分辨率像素 + 最近邻放大**
- 世界画在 1920/px × 1080/px 的小画布上：**px = 5 远景（384×216）、6 中景、8 近景、12 特写**。镜头"推近"= 换 px，不是缩放像素。
- 小人 20~28 像素高，朝右；**8fps 跳帧**（`Math.floor(t * 8)`），不插值；围巾 6fps 飘。表情靠动作（抱膝、举灯、站起、跪着钉钉子、落水只露头）。
- 横版分层：天（9 色渐变 + Bayer 抖动）→ 云带 → 月亮（像素圆 + 陨石坑）→ 海平线 → 海（浪花短横线、月光碎银倒影）→ 礁石 → 人。

**2. 光：硬像素上叠全分辨率软光（质感来源）**
- 第二个全分辨率 `Canvas2D`，`lighter` 模式画径向光晕：提灯（金）、月亮（蓝紫）、船灯（冷白）、冲击波闪光。
- 灯在海面上的暖光 = 一个被压扁的 glow（`scale(1, .22)`）；像素层另有碎金倒影（`lampRefl`）。
- 只有像素没有光 = 廉价小游戏；光多到糊掉像素 = 失去风格。

**3. UI：全部像素字（`F.pixel`，字号 12 的倍数）+ RPG 硬边框**
- **HUD 状态面板一直挂着**（左上角，`STATUS` 标签）：状态（等待救援 → 准备出发 → 航行中 → 靠岸）、天数 `DAY 0638 ▶▶`、信号 `发出 416 / 回应 0`（0 变红闪）。
  剧情推进 = 数值变化；天数飞涨（指数曲线滚动）就是"时间过去了很久"。
- **选择菜单是母题**：「谁能救我？」—— 家人 / 朋友 / 公司 / 运气 一项项被划掉（红线 + 红色标签"已读不回"弹出 + 撕裂抖动），
  最后一项「？？？」上锁；片尾菜单再出现，锁裂开 → 「我自己」。
- **获得物品卡**（右上角滑入）：木板 ×1、回应 ×1 …… 把抽象的进展变成"拿到了东西"。
- **片名砸下**：168px 金色像素字 + 8px 硬投影 + 辉光，天空里一圈像素冲击波，下面英文副标题打字机。
- **字幕**：像素字 48px、深色底条 `rgba(10,12,24,.82)` + 左侧 4px 竖线，逐字打出；`**词**` 金（自己）、`「词」` 冷蓝（别人）。

**4. 颜色就是语义**
| 用途 | 颜色 |
|---|---|
| 夜空（上 → 下） | `#080a15` → `#353f74`（9 级 + Bayer 抖动） |
| 海（近 → 远） | `#20284c` → `#090b19` |
| 自己 / 提灯 / 围巾 / 获得 | 金 `#f2c14e`、热金 `#fff0b8` |
| 别人 / 等待 / 船灯 | 冷蓝 `#9fb4ff` |
| 拒绝 / 划掉 / 回应 0 | 红 `#e8344a`、亮红 `#ff5a6e` |
| UI 线框 / 次要字 | `#6b7398`；主要文字 `#e6e9f2` |
| 黎明（结尾） | 天 `#1a1c3c` → `#f6b866`，海倒影 `#ffd890` |
| 暴雨（低谷） | 灰紫 `STORM` 调色板 + 闪电 flash |

**5. 叙事：把处境做成游戏机制**
- 抽象 → 数值 / 物品 / 状态：求助 = 发信号（回应 0）；努力 = 捡木板（12/12）；失败 = "船体损毁"、木筏散架；情绪 = 砸在木筏上的字（"焦虑""委屈"），积水 87%。
- 世界随情绪换天：平静 = 蓝夜（`NIGHT`）；低谷 = 暴雨（`STORM`，`mix` 用 Bayer 抖动渐变过去）；抵达 = 黎明（`DAWN`）。
- 收尾：母题回收（菜单解锁、灯连成航道、一排木筏划向太阳）。

## 四、怎么做（`@styles/pixel`）
```ts
import { NIGHT, STORM, DAWN, begin, flush, finish, rock, lampRefl, raft, oar, flag, rain, splash, bubbles, line,
         lightBegin, lightEnd, lampLight, lampFlicker, glow, ring, sitSprite, standSprite, rowSprite, drawSprite, drawLantern,
         plankAt, miniPerson, HERO, OTHERS, HZ, C, GOLD, COLD,
         PixelSub, HUD, Bar, Menu, Toast, SlamTitle, Icon, ICONS } from '@styles/pixel';
```
**一帧怎么画**（两层 Canvas2D，见示例 Main.tsx）：
```ts
const frame = (t) => ({ t, px: 5, camX: 0, camY: 50, mood: NIGHT, moon: { x: 284, y: 94, r: 15 }, iris: { x, y, r } });
// 像素层：<Canvas2D scale={1 / 5} style={{ imageRendering: 'pixelated' }} draw={...}>
const P = begin(g, frame(t));          // 天 / 海 / 云 / 月 / 星 / 浪 / 倒影 写进 ImageData 缓冲（逐像素，最快）
rock(P, 140, 196, 1, lamp);            // 缓冲阶段的东西用 P.put（礁石、灯的碎金倒影）
flush(g, P);                           // 贴上去；之后用 fillRect 画精灵（世界坐标）
drawSprite(g, sitSprite(t), x, y, { col: '#f6d58a', a: .3, dir: 1 });   // 边光：灯在右边就 dir 1
finish(g, P);                          // iris 圆形遮罩
// 光层：<Canvas2D draw={...}>（全分辨率）
const S = lightBegin(g, frame(t)); lampLight(g, S, lx, ly, lampFlicker(t), flash, waterY); lightEnd(g);
```
- **坐标全取整**；圆和斜线不用 `arc`/`lineTo`（边缘半透明），用逐像素判断 / Bresenham（`line`、`ring`）。
- 精灵：`sprite([[x0,y0,x1,y1,'#col'], ...])` 矩形拼格子；换 `Pal` 就是别的人（`OTHERS`）。新姿势照着 `sprites.ts` 里的写。
- 渐变一律**调色板 + Bayer 抖动**（`dpick`），不要平滑渐变。着色器背景（熔岩、峡谷）也要量化 + bayer4（见本文附录）。
- 转场：硬切 / iris 圆形遮罩 / 像素溶解（Bayer 阈值逐格切）/ 换 px 推近。**不用电影式柔和叠化**。
- 动效：弹入 `spring(t, 3.2, .45)` 1.4 → 1，落定震屏 2~3 帧（整层按整像素 translate）；数值滚动；冲击波像素圆环 0.4~0.7 秒淡出。
- 透明度也按 4 档走（`stepA`），像素游戏没有细腻淡入。
- `post.json`：`{ "grain": 2.5, "vignette": 0.28, "bloom": 0.24, "bloomThreshold": 0.6, "bloomRadius": 26 }`（颗粒调低，会和像素打架；**不加 bars 黑边**）。

## 五、声音
夜海底噪（`underwater` -24 左右当海浪）+ 游戏音：菜单打字 `tick`（pitch 1.6~2.0）、划掉 `glitch`、获得物品 `jingle`（pluck，E5 G5 B5 E6）、
天数滚动一串 `tick`、落水 `splash`、雨 `rain`、片名 `impact` + `shimmer`。少用 `swell` 这种电影铺底。只配关键节点，数量由动作和转折决定，不凑固定 cue 数。

## 六、踩过的坑
- 像素字字号不是 12 的倍数 → 笔画糊；DOM 里加 `WebkitFontSmoothing: 'none'`。
- 亚像素移动会让边缘闪：镜头、人物位移都 `Math.round`。
- 天数用线性滚动没感觉，用 `p^2.2`（先慢后飞涨），旁边挂 `▶▶` 表示快进，同时让云和浪也快进（`timeLapse`）。
- HUD 一直挂着会抢戏：情绪段落（抬头看天、暴雨）把它压暗到 45%。
- 菜单选项划掉要有"按下去"的瞬间：红底闪 0.1 秒 + 横向撕裂抖动 + 标签 1.6 → 1 弹出，不然像 PPT。

## 附：着色器背景的像素化（熔岩、峡谷、红雨）
`<Shader scale={.25} style={{ imageRendering: 'pixelated' }}>`，输出前量化 + 4×4 Bayer：
```glsl
float bayer4(vec2 p){ vec2 q = mod(floor(p), 4.); int i = int(q.x + q.y * 4.);
  float m[16]; m[0]=0.;m[1]=8.;m[2]=2.;m[3]=10.;m[4]=12.;m[5]=4.;m[6]=14.;m[7]=6.;m[8]=3.;m[9]=11.;m[10]=1.;m[11]=9.;m[12]=15.;m[13]=7.;m[14]=13.;m[15]=5.;
  for (int k = 0; k < 16; k++) if (k == i) return m[k] / 16.; return 0.; }
// c = floor(c * n + bayer4(gl_FragCoord.xy)) / n;   （WebGL1 不能用变量下标取局部数组，所以循环比较）
```
