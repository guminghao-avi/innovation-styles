# 风格 09：3D 渲染（软糯材质 · 物理弹跳）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **三维材质、灯光与物理弹跳 · 软糯、有分量 · 一地胶囊 + 一颗铬球 · 粉嫩的影棚光**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 05 种（作品 soft.「柔软着陆」：8,700 颗胶囊铺地，铬球砸成句号；原片用 Blender Cycles + Python 建模）。
> 工具：`@styles/soft3d`（GLSL 光线步进）；示例：`projects/示例_3D渲染/`（镜头滑过胶囊地 → 铬球落下弹两下，砸出一圈涟漪 → "soft." 落下）。

## 一、一句话认出它
像 C4D / Blender 渲出来的产品片：大量重复的柔软小物体（胶囊、球、方块）铺满画面，粉色或奶油色，柔和的大面积光、软阴影、环境光遮蔽；一个反光的铬球 / 主体物理地砸进去，周围的东西被推开。

## 二、什么题目用它
品牌 / 产品片、"柔软 / 治愈 / 有分量"的概念、需要高级质感的开场或片名。

## 三、长什么样
- 材质：粉 `(1, .55, .65)` → 薰衣草 `(.8, .58, 1)` 渐变，包裹光（wrap lighting）让暗部不死黑 → "软"；柔和高光。
- 光：一盏主光（左上）+ 半球环境光（天亮地暗）+ 软阴影 + AO；远处融进粉色背景（空气透视）。
- 铬球：只反射一张环境图（天 / 地渐变 + 地平线暗带 + 两块柔光箱）+ 菲涅尔，就已经很"铬"。
- 运动：解析弹跳（`bounceY` 恢复系数 .42）、冲击波（胶囊高度按距离 + 时间做一圈下沉的波）、镜头缓慢滑动。

## 四、技术实现方案（无 GPU 下的"渲染器"）
**一个 GLSL 光线步进着色器（`SOFT3D`），scale 0.5。** 这是程序化材质和运动的现成示例，包含软阴影与 AO；没有真实刚体/软体求解，也没有路径追踪全局光照。先测本机短片耗时。
- 场景 SDF：`域重复`（`floor(p.xz / S + .5)` 取格子 id）→ 每格一根胶囊（`length(q - clamp(q.y, R, h-R)) - R`），高度 `capH(id)` = 随机 + 冲击波；地面 `p.y`；球 `length(p - ball) - r`。
- **关键坑：每格高度不同 → 距离场在格子边界不连续 → 会"切片"。要同时查自己 + 朝向 p 的 3 个邻格**（`o = sign(g - id)`，4 次 capsule 取 min）。步长再乘 .75。
- 法线：四面体差分；软阴影 18 步；AO 4 次采样；包裹光 `(dot(n,L) + .45) / 1.45`。
- 镜头在 TS 里算（`uCam`、`uTgt`），解析弹跳（球的高度、第一次落地时刻）也在 TS 里算好传进去。
- 需要真实碰撞、软体或更复杂的光照时，按 [工具选择](工具选择.md) 另外制作离线三维工程，再将渲出的序列帧/视频与字幕、声音合成。当前包没有 Blender 工程。
- `post.json`：`{ "grain": 3, "vignette": 0.2, "bloom": 0.15 }`；曝光 0.8（ACES 下 1.0 会发白发灰）。

## 五、声音
柔软的落地：`impact` size .3 + 低通（闷），回弹 `pop` 越来越轻；胶囊被挤压的"噗噗"可以用很轻的 `bubbles`；片名 `swell`。

## 六、坑
- 不查邻格 → 胶囊被切成薄片、半透明鬼影。
- 曝光太高：粉色全变奶白、没有体积感。
- 铬球环境太均匀 = 珍珠，不是铬；地平线暗带 + 高亮柔光箱的强对比才是"金属"。
