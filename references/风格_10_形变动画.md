# 风格 10：形变动画（Shape Morph）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **一个形状连续变成下一个 · 形状本身就是叙事 · 一滴墨变成咖啡、太阳和海鸥**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 06 种（作品 morphe.「一形万象」）。
> 工具：`@styles/morph`；示例：`projects/示例_形变动画/`（墨滴落下 → 咖啡杯（冒热气）→ 落日 → 海鸥扇翅飞走 → 缩成 "morphe." 的句号）。

## 一、一句话认出它
画面中间只有一个实心形状，它不停地"流"成别的东西，颜色和背景也跟着变；没有剪辑点，整条片子是一个形状的一生。

## 二、什么题目用它
品牌 / 概念的"一以贯之"、一件事的演变（原料 → 产品 → 场景）、诗意的联想链；适合短（10~40 秒）。

## 三、长什么样
- 单色实心形状（不描边），一个画面一个形状 + 一个背景色；颜色和背景在形变中同步插值。
- 形状库保持"同一种笔法"：圆润、简洁的剪影（墨滴、杯子带把手、锯齿太阳、M 形海鸥、圆点）。
- 形变：点按序号错开一点时间（stagger .25）→ 像液体流过去，不是整体溶解；每次 0.9~1 秒，中间停 1~2 秒让人看清。
- 小配件（热气、光芒）在形状成形后才出现，变走前先散掉。

## 四、技术实现方案
**所有形状先变成"同样点数的闭合多边形"，再对齐起点，最后逐点插值。**
```ts
import { resample, align, morph, toD, drop, cup, sun, gull, circle } from '@styles/morph';
const KEY = [drop(...), cup(...), sun(...), gull(...), circle(...)].map(p => resample(p, 180));
for (let i = 1; i < KEY.length; i++) KEY[i] = align(KEY[i - 1], KEY[i]);   // 起点对齐：不然会"拧麻花"
<path d={toD(morph(A, B, u, .25))} fill={mixColor(a, b, u)} />
```
- `resample`：按周长均匀取 N 点（N = 120~200）；`align`：把 B 的起点旋转到总距离最小的位置。
- 动态形状（海鸥扇翅）：每帧生成 `gull(..., flap)` 再 resample + align 到上一个关键形状。
- `@remotion/paths` 的 `interpolatePath(u, d1, d2)` 也能直接插两个 path 字符串，适合命令结构相近的路径；形状差异大时用上面的重采样法更稳。
- `post.json`：`{ "grain": 2, "vignette": 0.15, "bloom": 0 }`。

## 五、声音
每次形变一个"流体"声（`whoosh` 短 + 很轻的 `bubbles`），成形时一个对应的小音效（咖啡 `ding`、海鸥 `whoosh` 上扬、句号 `pop`）。

## 六、坑
- 点数不同 / 不对齐 → 形变时翻转打结。
- 带孔的形状（杯把手的洞）在单个多边形里做成"外圈 + 内圈来回走一趟"，不要用两个子路径。
- 句号终点：渲静帧量字标位置。
