# 风格 11：贴纸风科普（Sticker Explainer）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **粗白描边的贴纸图形 · 把硬核知识拆成看得懂的图 · 超大画布 + 相机运镜 · 零件、周期表、地图一路推下去**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 07 种（作品「一部手机里，藏着多少种元素？」）。
> 工具：`@styles/sticker`；示例：`projects/示例_贴纸风科普/`（手机贴纸拍下来 → 推到电池（Li、Co）→ 平移到芯片（Si、Ga）→ 拉远，元素周期表亮起约 70 格）。

## 一、一句话认出它
浅灰点阵纸上贴满了贴纸：每个图形外面一圈粗白边 + 一点投影；镜头在一张很大的画布上推、拉、平移，一站一站讲；标签是"黑体大字 + 英文小字 + 引线 + 圆点"；化学元素是一个个带序号的小方块。

## 二、什么题目用它
硬核科普：拆解（手机、汽车、身体）、成分、地图、流程；信息量大但要轻松好懂。

## 三、长什么样
- 底：`#f2f1ee` + `#cfcdc6` 点阵（36px 间距）。
- 贴纸：平涂插画 + 7px 白描边 + 投影（`3px 7px 6px rgba(40,30,20,.28)`），每张微微歪 ±2~6°。
- 标签：思源黑体 900 64px + Grotesk 小字宽字距英文；引线 4px 黑线 + 端点白边黑圆点；先画线再出字。
- 元素小方块：圆角深色 + 白边，序号 / 符号 / 中文名；按出场弹入。
- 运动：贴纸"拍"上去（spring 弹入）；镜头 `E.film` 推拉（每站停 1.5~3 秒）。
- 颜色：红 `#e5483b`、蓝 `#3c6fd8`、黄 `#f4b93a`、绿 `#3caa6e`、墨 `#1d1d22`。

## 四、技术实现方案
**一个比屏幕大好几倍的 DOM "画布"（4400×2600），所有内容按画布坐标摆；镜头 = 画布整体的 CSS transform。**
```tsx
import { STK, StickerDefs, DotGrid, Chip, Label, camAt } from '@styles/sticker';
<StickerDefs />                                    // 一个 SVG 滤镜 #stk：膨胀出白边 + 投影
<div style={{ width: 4400, height: 2600, transformOrigin: '0 0', transform: camAt(t, [[0, {x, y, s}], ...]) }}>
  <DotGrid w={4400} h={2600} />
  <svg><g filter="url(#stk)"> 任何矢量图形 </g></svg>     // 自动变贴纸
  <Label x y lx ly cn="电池" en="BATTERY" t={...} />   <Chip x y n={3} sym="Li" name="锂" t={...} />
</div>
```
- 白边滤镜：`feMorphology dilate`（白边宽度）→ `feFlood` 白 → 合成；再一路 `feGaussianBlur + feOffset` 做投影；`feMerge` 叠起来。任何 SVG 组套上就变贴纸。
- `camAt` 的关键帧是"画布上哪个点放到屏幕中心 + 缩放"，用对数插值缩放（`keys(..., ['s'])`）。
- 元素小方块 / 卡片用 DOM（`box-shadow: 0 0 0 8px #fff` 做白边最便宜）。
- 性能：DOM + SVG 滤镜；先在目标尺寸检查描边裁切与耗时，避免过大的滤镜区域。
- `post.json`：`{ "grain": 1, "vignette": 0.1, "bloom": 0 }`。

## 五、声音
贴纸拍下来 `slap`（小）、标签出现 `tick`、元素弹出 `pop`（按音阶升高）、镜头大移动 `whoosh`、最后的大数字 `impact` 小。

## 六、坑
- 起始镜头太近，主体被切掉；每个停靠点都渲一张静帧看构图。
- 拉远看全貌时最右边的内容出画：用所有内容的包围盒算中心和缩放。
- 贴纸白边太细（< 5px）在缩小时看不见。
