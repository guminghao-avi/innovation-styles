# 风格三：写实电影感（着色器做光 · 一个发光母题 · 纪录片字幕）

> **黑暗里的光 · 一个从头跟到尾的发光母题 · 宋体字幕逐字对焦 · Garamond 读数 · 克制、诗意、像纪录片**
> 来源：《光：十七万年零八分钟》《回声》《那我呢》《狮子之心》《握不住的水》《冰山之下》（`projects/参考_那我呢/` 是完整源码）。
> 工具：`@styles/cinema`；最小示例：`projects/示例_写实电影感/`（25 秒：夜湖地平线上一句话的波形响起又散掉 → 脑子里一百遍 → 带回声衰减 → 黎明 → 片名）。

## 一、一句话认出它
几乎全黑的画面里只有一样东西在发光（一根琥珀色的线、一颗星、一个光点、一条光做的鱼），它从第一个镜头跟到最后；
天空、水、山、云都是着色器算出来的，暗部真暗、亮部只占 10~20%；字幕是思源宋体，一个字一个字从虚焦里对上焦。

## 二、什么题目用它
- **情绪向、哲思向、浪漫的科学**：为什么人会反复想说错的话、星座性格、存在主义、宇宙尺度、记忆、时间。
- 有一个能"发光"的母题（光、声音、线、星、水、火）。
- 不适合：密集信息、需要大量 UI 和数值、轻松搞笑（→ 潜水戴夫风 / 纸艺手绘）。

## 三、长什么样
**1. 光与色**
- 着色器里线性颜色 × 曝光 → `aces()` → `toSRGB()` → `dither()`。曝光先压低，值给大了 ACES 一压全变奶油色。
- 一个画面只一个视觉焦点，最亮的就是观众该看的。颜色系统 3 色以内：例《回声》琥珀 = 你、冷灰蓝 = 世界、红 = 警报。
- 后期：`post.json` 默认 bloom .18、grain 5、vignette .25，可加 `bars: 2.39` 宽银幕黑边。

**2. 母题贯穿 + 形变转场**
- 同一个东西换形态（波形 → 山脊 → 重播隧道 → 线团 → 地平线），镜头之间靠它衔接，不硬切。
- 每个镜头一个"招牌画面"（被截图会有人问怎么做的）：比如波形放大成夜里的一座山、湖面倒影。

**3. 文字**
- 字幕 `CineSub`：思源宋体 50px、字距 .09em，逐字虚焦对焦（每字 .035 秒），`**词**` 琥珀、“引号”冷白；下方一团很淡的径向压暗代替黑底。
- 读数 `Readout`：宋体小标签（22px，宽字距）+ Garamond 大数字，像纪录片（"时长 1.96 s""第 100 遍""46% / 23%"）。全片 2~3 组。
- 片名 `CineTitle`：宋体 104px 宽字距逐字对焦 + 一条细光线 + 英文小字；亮背景（黎明）上用 `bright` 加深色描影。

**4. 节奏**
- 开头 3 秒内就有画面事件 + 钩子句；转场 / 大画面前留 1.5~3.5 秒呼吸；高潮前抽空（硬切黑场 + 静音 1~1.5 秒）效果极好。

## 四、怎么做（`@styles/cinema` + kit）
```tsx
import { LAKE, glow, glowLine, CineSub, CineTitle, Readout, Dust, AMBER, AMBER_HOT, RED, COLD } from '@styles/cinema';
<Shader frag={GLSL.noise + GLSL.color + LAKE} scale={.5} u={{ uCy: 600, uAmp: 0, uFade, uExpo: .9, uDrift: t * .004, uFar: .32, uDawn, uXc: .5, uW: .012 }} />
<Canvas2D draw={g => { g.globalCompositeOperation = 'lighter'; glowLine(g, pts, AMBER, AMBER_HOT, 1); }} />
```
- `LAKE`：夜空 + 星 + 月光、三层远山（大气透视）、可选前山（`uAmp > 0`，山脊 = `ridge(x)`，改成你自己的曲线）、水面倒影、薄雾；`uDawn` 0→1 换成黎明。
- 发光线 `glowLine`（四层描边：14px 淡 → 5px → 2px → 0.9px 白热芯）、光晕 `glow`（径向渐变）都在 `lighter` 模式下画。
- 更多着色器写法（等离子体、星云、虹膜、行星、云、雪原、聚光灯、2.5D 山）看 `projects/参考_那我呢/shaders/` 和本文附录 A。

## 五、声音
全合成、只配关键节点：母题有自己的声音（《回声》里那句话 = `mumble` 含糊人声，同一个种子，每次重播都是同一句）；
低语 `whisper` 层层叠起 → `riser` → **硬切静音**（sound.json 的 `mute`）；结尾真的回声（同一句 mumble 延迟 0.55 秒、越来越闷越轻）+ 黎明 `swell`。一直留一层 `air`。

## 六、踩过的坑（精选，完整版见本文附录 A）
- 山脊只按斜率打光 = 一条条竖纹"窗帘"；用 2D 噪声梯度打光，前山压暗成剪影更真。
- 湖面倒影的发光线别和实线一样亮（.14~.4），并且随波纹微微起伏。
- 黎明的亮天空上，白色片名副标题和细线会看不见：加深色描影。
- 3D 镜头先算再摆（俯冲、绕行时主体容易出画）；重播隧道这类纵深镜头要把近端框在字幕上方。

## 附录 A：手艺清单（做示例片时真实踩过的坑，每张静帧都对着它挑）
**这些都是做示例片时真实踩过的坑。每张静帧都对着它挑。**

光与色
- **曝光先压低**：着色器里线性颜色 × 曝光 → `aces()` → `toSRGB()`。值给大了 ACES 一压全变奶油色（"焦糖大理石"）。
  亮部只占画面 10~20%，暗部要真暗。热的东西：`v^2.6~2.9` 做对比，颜色从暗红 → 橙 → 金 → 白热按 v、v²、v³ 叠。
- **饱和的橙/蓝要压低另外两个通道**：想要线性 (1, .3, .03) 这种，蓝通道一高就发白。
- **所有渐变、光晕输出前 `dither()`**，否则暗部出一圈圈色带。
- 一个画面只一个视觉焦点，最亮的东西就是观众看的东西（示例：蓝白的光点在橙红等离子体里）。
- 字幕区域：画面下 1/4 别放大亮块；天空这种亮场景，在着色器里让画面下部自然变暗，比加黑底高级。

真实感
- **"假"的东西宁可不画**：示例里画眼睑皮肤一眼假，改成"虹膜摄影"风格（只有虹膜，四周压黑）立刻变真。选一个能藏住弱点的审美。
- **规则 = 假**：网格排列的斑点、等宽的缝、完美的圆。随机要有簇（noise 做 mask）、有大小差异、有方向（顺着纤维拉长）。
- **镜面反光边缘是锐的**（角膜、玻璃、水），但要小、要被曲面压弯；大块白色圆角矩形像 UI 图标。
- **跟着物理走的小细节最打动人**：光进眼 0.25 秒后瞳孔才收缩、地球侧光看得到明暗交界线、太阳临边昏暗 + 色球层红边、米粒组织越远越淡（按像素覆盖做 LOD，不然闪烁）。
- 微距/景深：画面边缘降低高频细节（假景深），比真模糊便宜得多。
- 球体/圆盘边缘用 `smoothstep(1-aa, 1+aa, r)` 抗锯齿，aa = 一个像素在你坐标系里的大小。
- **剪影藏拙**：建筑、人物这种难做真的东西，放到逆光里只画剪影（大落日前倒塌的石柱、走向落日的小人），再给朝光一侧一道细亮边 + 按距离被霾冲淡。
  几何体边缘随机缺角（2~9%），完美矩形一眼假；但缺得太多又像棉花糖。
- **地貌（2.5D 层叠山）**：只按山脊线的斜率打光 = 一条条竖纹（"窗帘"）。要用 2D 噪声的梯度给岩面打光，山边缘 `smoothstep` 抗锯齿，着色器 scale ≥ .7。
- **透视地面**：地面坐标 Z = k/(地平线距离)，所有纹理按 (X, Z) 采样；k 太小近处的纹理一片平（看不到光斑和草），近景还要加一层高频质感。
  移动的云影（地面上一块块被照亮的光斑）是风景"活"起来最便宜的办法。
- 一个"东西"变成另一个"东西"（栅栏 → 碎片）：粗、饱和的彩色线段像糖果棍，**化成余烬/粒子**更高级；碎段 0.4 秒内淡出。
- 同一组线**形变**成新形状（栅栏 → 羽翼）比切换更有说服力：每条线采样同样多的点，逐点插值，按序号错开时间。
- Canvas 画半透明的路/带子：一段段 `lineCap: round` 的线会叠出一串珠子；画成一个多边形带子（左右边各一串点）。

镜头
- **3D 镜头算清楚再写**：贴近球面时地平线下沉角 = acos(R/(R+h))，h=0.1R 就已经下沉 24°，画面里看不到地平线。先算再摆。
- 快速运动的主体要么镜头跟（仰拍追火箭那样把 target 插值到主体上），要么镜头离远；否则 0.1 秒就出画。
- 拉远框住一团东西：用**前缀包围盒**（已走过的点的 min/max）做中心和缩放，不要用重心（会偏）。
- 运动要有加速度：起步慢、收尾长（`E.film`），关键时刻 `t^2.4` 越冲越快。
- 倒塌、坠落用真物理：杆绕底边倒下 θ'' = 1.5·g/L·sinθ（预先积分成查表），初始角别太小（0.09），否则前一两秒几乎不动。
- 场景之间用母题衔接：光点冲出核心 → 白闪 → 同一个光点从太阳表面升起；云的白 → 叠化成虹膜；黑场 1 秒 → 片名。

文字
- 字幕 50px（见固定要求），下方 1/4 别放大亮块；少即是多：全片只有字幕、2~3 组读数、片名。读数用 Garamond 数字 + 宋体小标签，像纪录片，不像 PPT。
- 读数必须和画面一致（距离归零的那一刻就是进入大气的那一刻）。
- 片名：宋体大字宽字距，`Reveal mode="blur"` 逐字对焦 + 一条细光线 + 英文小副标题。

## 附录 B：声音配方（用户要配乐时才用乐器 cue；默认只用其中的音效部分）
- **宇宙/史诗**：drone D2 + sub D1 打底，strings 慢和弦（bright .4~.5，verb .6+），glass 慢琶音点缀；高潮 riser 2s → impact size 1 + boom。
- **微观/紧张**：pulse（76 bpm 八分）+ drone beat .35（拍频不安）+ 事件点 ding（五声音阶里挑音）+ type 由疏到密。
- **温柔/收尾**：keys 单音旋律，句子落点处一个音；最后一个和弦 4 个音错开 30ms 像真人弹。
- **抽空**：automation 在高潮前 0.5 秒把配乐压到 -20dB，只留心跳/呼吸，然后在冲击点回到 0。
- 整片一直留一层 `air`（-30dB）：真正的静音听起来像坏了。
- **sub 占比容易超标**：drone + sub + boom + thunder + kick 叠起来轻松 20%。先把 sub cue 压到 -35dB 左右、boom -18 左右，再看 audiocheck。
- 雷用 `thunder`（near=1 头顶炸雷，0 远处闷雷），火（篝火、火焰写字）用 `fire`。
