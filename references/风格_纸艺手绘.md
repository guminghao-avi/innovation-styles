# 风格四：纸艺手绘（剪纸立体书 · 定格动画 · 墨线小人）

> **一切都是剪下来的纸：平涂色 + 不规则剪边 + 落在后一层上的软影 + 纸纹 · 12fps 一拍二的定格感 · 粗墨线手绘小人 · 胶带纸条字幕 · 拟声词贴纸**
> 工具：`@styles/paper`；最小示例：`projects/示例_纸艺手绘/`（22 秒：日历页"今天"→ 纸条一张张摞成"明天/下周/下个月"的塔 → 小人扭头"躲！"→ 只做两分钟：塔一张张飞走 → 片名纸片落下）。

## 一、一句话认出它
像一本立体书被拍成了定格动画：纸剪的太阳一格一格转，山是一层层叠起来的彩纸、每层底下有一道软影；
一个圆脑袋的墨线小人站在中间，表情很简单；字幕写在一条撕下来、两头贴着胶带的纸条上。**温暖、手作、好笑、有生活气。**

## 二、什么题目用它
- **生活里的小比喻、小故事、心理小机制**：拖延、内耗、社交、做饭、通勤、存钱、减肥……有实物、有动作的。
- 题目能变成**一个小人 + 几样纸做的道具**的小剧场（日历、纸条、塔、钟、碗、手机）。
- 想要亲切、不说教、带一点幽默。
- 不适合：宏大 / 宇宙 / 史诗（→ 写实电影感）、需要大量数值面板（→ 潜水戴夫风 / 自渡风）。

## 三、长什么样
**1. 剪纸（`paperShape` + `cutEdge`）**
- 每样东西 = 一个多边形：**平涂一种颜色**（不要渐变）+ **剪边**（`cutEdge` 给边加不规则的小缺口，种子固定 → 不乱跳）
  + **投影**（落在后一层上，越靠前的层 `lift` 越大、影子越远越软）+ 左上一道很淡的亮边（纸的厚度）。
- 场景分层：天（一整张纸）→ 太阳 / 云 → 远山 → 近山 → 地面 → 道具和人。推镜头时按层视差（远 .2~.5、近 1~1.5）。
- 最后整帧 `overlayPaper(g, .6)` 用 multiply 盖一层纸纹（纤维 + 斑点），所有颜色立刻变"纸"。

**2. 定格（`stepT` / `beat`）**
- 所有运动的时间先吸附到 12fps（`stepT(t)`）：位置、旋转、缩放一格一格走 —— 这就是定格动画的"顿"。
- 纸片落下 / 弹出用三拍：先大 / 先高（1.35 或 -60px）→ 回弹一点（.92 或 +8px）→ 落定，**不用平滑缓动**。
- 墨线每两拍抖一次（`boil`：`inkLine(g, pts, beat(t) >> 1)`），手绘感的来源；剪纸边也可以跟着 boil 微抖（`cutEdge(..., b)`）。

**3. 墨线小人（`inkPerson`）**
- 纸做的身体（藏蓝）+ 奶白纸圆头 + 墨线描边 + 线条四肢（7px 圆头线）；表情只有 calm / worry / smile / shock；`arm` 举手，`walk` 走路相位。
- 情绪靠表情 + 小符号（汗滴、问号、心）+ 贴纸，不靠复杂动作。

**4. 文字**
- 字幕 `PaperSub`：撕边纸条（`clip-path` 不规则多边形）+ 两头半透明胶带 + 思源宋体 700 50px 墨色；`**词**` 赤陶红 + 波浪下划线、`「词」` 藏蓝；每句出现时按拍"拍"下来，纸条随机歪 ±0.8°。
- 拟声词贴纸 `Sticker`：锯齿爆炸框（芥末黄 / 玫瑰）+ 得意黑大字 + 投影，按拍弹入，每拍轻轻摇（"躲！""开工！""咔嚓""叮"）。
- 片名 `PaperTitle`：每个字一张不同颜色的方纸片（赤陶 / 芥末 / 鼠尾草 / 雾蓝 / 玫瑰），按拍一张张"啪"地落下，各自歪一点；下面 Garamond 英文小字。
- 画面里的纸片道具上可以直接写字（得意黑），比如日历"今天"、纸条"下个月"。

**5. 颜色（低饱和、暖、像美术纸）**
| 用途 | 颜色 |
|---|---|
| 纸（底 / 纸条 / 头） | `#f4ecdc` / `#e9dcc3` |
| 天 | 雾青 `#cfe0e3` |
| 太阳 / 强调 | 芥末 `#f2b33d` `#e7b23f` |
| 地面 / 重点词 | 赤陶 `#d9734e`、重点字 `#c4532f` |
| 山 | 鼠尾草 `#9cb48a` / 深 `#6f8f68` |
| 人物衣服 / 第二强调 | 藏蓝 `#3b4a6b` |
| 其他 | 玫瑰 `#e58f86`、雾蓝 `#7fa6c9`、墨 `#2b2622`、胶带 `rgba(240,228,190,.72)` |

## 四、怎么做（`@styles/paper`）
```tsx
import { P, stepT, beat, overlayPaper, cutEdge, paperShape, hillPts, circlePts, rectPts, inkLine, inkPerson, Sticker, PaperSub, PaperTitle } from '@styles/paper';
<Canvas2D draw={(g, t) => {
  const st = stepT(t), b = beat(t) >> 1;
  paperShape(g, cutEdge(hillPts(760, 90, .006, 4.1), 61, 2), P.sage, { lift: 1 });     // 一层山
  paperShape(g, cutEdge(rectPts(x, y, 300, 44, rot, 6), 70 + i, 1.4), P.paper, { lift: .7 });   // 一张纸条
  inkPerson(g, 700, 880, b, { s: 1.15, mood: 'worry' });
  overlayPaper(g, .6);                                                                 // 最后：纸纹
}} />
```
- 全部在一个全分辨率 Canvas2D 里从后往前画（剪纸层数不多，很快）；DOM 只放字幕、贴纸、片名。
- 投影用 canvas `shadowBlur`，每帧几十个形状没问题；上百个时把远层合成一张缓存。
- `post.json`：`{ "grain": 4, "vignette": 0.3, "bloom": 0.05, "bloomThreshold": 0.8 }`（纸不发光，bloom 几乎关掉；暗角让它像台灯下的桌面）。

## 五、声音
纸的声音为主：纸片落下 `slap`（每张一下，size .6~1.2）、飞走 / 翻动 `paper`、红笔圈画 `scribble`、贴纸 `pop`、剪断 `snip`；
片名每个字一下 `slap`。没有铺底音乐，只有很轻的 `air`。只配关键节点。

## 六、踩过的坑
- 平滑缓动会把定格感毁掉 —— 运动时间一定先过 `stepT`。
- 线条每帧都抖 = 闪烁；每两拍抖一次（`beat(t) >> 1`）刚好。
- 贴纸放在会长高的东西（纸条塔）上方会被挡 / 挡住重点；放在空天上。
- 纸纹 multiply 太重（> .7）整片发灰发脏；.5~.6。
