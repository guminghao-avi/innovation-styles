# 风格 17：16 位像素风（明亮像素冒险 · PIXEL QUEST）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **低分辨率、少量颜色、逐点摆放 · 16 位游戏机的味道 · 32 色调色板轮换出一整天的光**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 13 种（作品 PIXEL QUEST 像素冒险；标签 320×180 画布、调色板轮换）。
> 工具：`@styles/pixel16`（复用 `@styles/pixel` 的 Bayer / 噪声）；示例：`projects/示例_16位像素/`（横版世界卷动、小人跑、金币转，天色 黎明 → 正午 → 黄昏 → 夜）。
> 和"自渡风"的区别：自渡风是暗夜、孤独、叙事型（HUD + 菜单讲概念）；这里是白天、明亮、饱和的横版游戏世界，重点是视差卷动和调色板轮换。

## 一、一句话认出它
320×180 放大 6 倍的横版游戏画面：天空、远山、近山、松林、砖块地面一层层以不同速度卷动，小人在跑、金币在转，左上角 SCORE、右上角三颗心；天色从黎明变到夜晚，所有东西的颜色"一格一格"地换，而不是平滑渐变。

## 二、什么题目用它
游戏化叙事、成长 / 冒险 / 闯关比喻、怀旧、给小朋友讲东西；轻快、积极。

## 三、长什么样
- 画布 320×180（最近邻放大 ×6），每个像素都是"摆"上去的；没有抗锯齿、没有半透明。
- 4 套调色板（黎明 / 正午 / 黄昏 / 夜），每套 10 个槽位：0 天顶 1 天底 2 远山 3 近山 4 树暗 5 树亮 6 草 7 土 8 土缝 9 高光；场景只按"槽位"上色。
- 渐变用两色 Bayer 抖动（天空）；时段切换用 Bayer 阈值逐像素换色（像老游戏机的调色板动画）。
- 视差：远山 .2、近山 .5、松林 .8、地面 1.0 倍速；云更慢。
- UI：像素字 48px（12 的倍数）+ 4px 深色描边（8 方向 text-shadow）+ 硬投影；片名大字 144px 黄色；"PRESS START" 闪烁。

## 四、技术实现方案
**背景（天、山、地）逐像素写进 `ImageData`（最快），精灵用 `fillRect` 画；全部在 `<Canvas2D scale={1/6} style={{ imageRendering: 'pixelated' }}>` 里。**
```ts
import { PW, PH, PALS, slot, hex } from '@styles/pixel16';
const tau = 时间 → 0..3.2（黎明 → 夜）;
buf[y * PW + x] = slot(tau, 槽位, x, y);                // ImageData 用 u32（ABGR）
g.fillStyle = hex(slot(tau, 5, x, y));                   // fillRect 用 '#rrggbb'
```
- `slot(tau, i, x, y)`：`tau` 的整数部分选当前调色板，小数部分 `f` 和该像素的 Bayer 阈值比较 → 用下一套还是这一套的颜色（逐像素切换，不插值）。
- 地形高度：一维值噪声（`vnoise((x + cam×视差) × 频率)`）取整。
- 精灵：字符画（`'..rrrr..'` + 调色表），8fps 两帧跑步；金币 4 帧（宽 1→3→5→3）。
- 太阳 / 月亮：逐像素判断 `dx² + dy² ≤ r²` 画圆（不用 `arc`，避免半透明边）；月牙 = 圆减去偏移的圆。
- 性能：320×180 写缓冲 + 几百个 fillRect；保持低分辨率画布和最近邻放大。
- `post.json`：`{ "grain": 0, "vignette": 0.12, "bloom": 0.12, "bloomThreshold": 0.75 }`（像素风别加颗粒）。

## 五、声音
芯片音：跳跃 / 吃金币 `coin`、脚步 `tick`（8fps 对齐）、片名 `jingle`（pluck / square 风格上行琶音），按 PRESS START 一下 `ding`。

## 六、坑
- 用 `arc` / 平滑渐变：边缘出现半透明像素，像素风立刻不纯。
- 字号不是 12 的倍数：像素字糊。
- 两层抖动（天空渐变 + 时段切换）的 Bayer 要错开偏移（`bayer(x+2, y+1)`），不然图案叠在一起出规律纹。
