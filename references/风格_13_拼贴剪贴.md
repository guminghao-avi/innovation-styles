# 风格 13：拼贴剪贴（Collage · Cut-out）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **剪报、牛皮纸、网点印刷 · 12fps 的卡顿也是风格 · 绅士照被剪开脑袋，脑洞蹦了出来 · 绑架信式拼字**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 09 种（作品 NOGGIN 脑洞季刊；标签：抠图拼贴、逐格步进）。
> 工具：`@styles/collage`（+ paper 包的剪纸工具）；示例：`projects/示例_拼贴剪贴/`。
> 和"纸艺手绘"的区别：纸艺是干净的彩色剪纸立体书；拼贴是脏的、杂志 / 报纸 / 老照片混搭的 zine 风，更朋克、更幽默。

## 一、一句话认出它
牛皮纸底上啪啪啪贴上撕边的剪报（标题 + 一行行小字）、网点印刷的黑白老照片、半透明胶带；动作一卡一卡（12fps）；照片里的人被剪开、拼接出荒诞的东西；标题是不同字体、不同底色拼起来的"绑架信"字。

## 二、什么题目用它
脑洞、讽刺、反常识、文化 / 历史杂谈、"拆开看本质"；幽默、有态度、复古。

## 三、长什么样
- 底：牛皮纸 `#b98e5c`（程序化纤维 + 斑点，缓存成一张）。
- 剪报：`#ece6d6` 撕边纸 + 黑标题 + 灰色"字"（短横条，两栏）；网点照片（45° 网点，点大小 ∝ 暗度）；胶带 `rgba(238,226,190,.7)`。
- 强调：红 `#d6261f`、黄 `#ffd23a`、黑；红色剪刀虚线；圆形黑印章。
- 运动：**逐格步进**，所有时间先吸附到 12fps；贴上去三格落定（1.25 → .95 → 1）；剪开、掀起都按格走。
- 字：标题"绑架信"（每个字一块剪纸，字体 / 底色各不同，歪 ±7°）；字幕是一张歪着的纸条，重点词红底白字。

## 四、技术实现方案
**一层全分辨率 Canvas2D；照片不用真照片，用"暗度函数 → 网点"程序化画（无版权问题，而且天然有印刷感）。**
```ts
import { COL, kraft, newsprint, halftone, tape, tornRect } from '@styles/collage';
newsprint(g, x, y, w, h, seed, { head: 'THE MIND IS', font: F.cn });   // 一块撕边剪报（带投影）
halftone(g, x, y, w, h, (u, v) => 暗度0..1, 10);                         // 网点"照片"
tape(g, x, y, 170, -.1);
```
- 网点：在 45° 旋转的网格上取点，圆点半径 = `cell × .55 × √暗度`（√ 让中间调更自然）。
- "照片"的暗度函数：几何拼出来（高礼帽 = 矩形、头 = 椭圆 + 侧光渐变、肩 = 梯形、眼睛 = 小圆）——剪影 + 网点 = 老照片的错觉。
- 剪开：同一张卡片画两次，分别用 `clip` 裁上半 / 下半；上半绕剪口旋转 + 平移掀起；中间插入"脑洞"。
- **静止的网点图一定先画到离屏画布里缓存**（`document.createElement('canvas')` 画一次，之后每帧 `drawImage`）：避免每帧重复绘制几千个圆点。本示例已缓存网点和纸底，实际耗时以本机短片测试为准。
- 牛皮纸底只生成一次（`document.createElement('canvas')` 缓存），每帧 `drawImage`。
- 真照片素材：用户提供的照片可以先转灰度再按亮度做 `halftone`（`getImageData` 取亮度）—— 立刻变成拼贴风。
- `post.json`：`{ "grain": 6, "vignette": 0.35, "bloom": 0, "eq": "contrast=1.05:saturation=1.05" }`。

## 五、声音
纸拍下来 `slap`、撕纸 / 翻动 `paper`、剪刀 `snip`、印章 `impact` 小、脑洞蹦出 `pop` + `jingle`（短、怪一点的音）。

## 六、坑
- 平滑动画会毁掉拼贴感 —— 运动时间一定先 `Math.floor(t*12)/12`。
- 掀起的部分飞出画面：掀起幅度控制在 150px / 25° 以内。
- 标题和主体打架：绑架信标题放在空的一侧。
