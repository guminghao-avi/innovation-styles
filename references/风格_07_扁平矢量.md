# 风格 07：扁平矢量（Flat Vector）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **纯色几何 · 零阴影零渐变 · 靠回弹和节奏讲故事 · 一颗珊瑚色圆点一镜长成品牌**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频第 03 种（作品 popwise「One Dot」）。
> 工具：`@styles/flat`；示例：`projects/示例_扁平矢量/`（圆点掉下来弹三下 → 长大变黄沉进地平线成日落 → 升起缩回，落在字标 "one dot." 的句号上）。

## 一、一句话认出它
一块纯蓝的底、一颗珊瑚色的点在弹，压扁、拉长、回弹，节奏感极强；所有东西都是纯色的圆、方、圆头短棒，没有任何阴影和渐变；最后收成一个品牌字标。

## 二、什么题目用它
品牌片、产品概念、一个抽象概念的"比喻小动画"（一个点 = 一个想法 / 一个人）；节奏快、干净、国际化。

## 三、长什么样
- 颜色 4~5 个，大面积纯色：蓝 `#2b3bdb` / 深蓝 `#1f2aa8`、珊瑚 `#ff5a4e`、黄 `#ffc93c`、奶白 `#f6efe3`、墨 `#141a3c`。
- 形状：圆、圆角矩形、圆头线段（光芒、倒影都是 `strokeLinecap: round` 的短棒）。
- 运动是灵魂：**真物理弹跳**（每次落地按恢复系数衰减）、**挤压拉伸**（下落拉长、落地压扁、面积守恒）、**过冲回弹**（出场 0 → 1.15 → 1）、**错峰**（一排元素间隔 0.06~0.08 秒依次弹出）。
- 转场：一个元素长大 / 缩小 / 移动成为下一幕的东西（点 → 太阳 → 句号）；整屏换色用"从点扩开的圆"。
- 字：几何无衬线（`F.en`）粗体，字母依次从下弹上来；中文黑体 800，不加描边阴影。

## 四、技术实现方案
**全部 SVG（DOM）**，矢量永远锐利；动画全是数学函数，不用补间库。
```ts
import { FLAT, bounceY, squash, overshoot, stagger } from '@styles/flat';
const b = bounceY(t, 840, 5200, .55);          // { y: 离地高度, v: 速度, hit: 距上次落地的秒数 }
const [sx, sy] = squash(b.v, b.hit);           // 速度越大越拉长，落地 0.12 秒内压扁（sx = 1/sy）
<g transform={`translate(${x} ${floor - b.y}) scale(${sx} ${sy})`}><circle cy={-r} r={r} /></g>   // 以底部为缩放中心
overshoot(t - stagger(i, t0, .07))             // 第 i 个元素的弹性出场
```
- `bounceY`：解析解（每段抛物线，速度 × e），不用逐帧积分，任意时刻可算。
- 圆点到句号：终点坐标要对着实际字标量（渲一张静帧量 "t" 的右边和基线），别估。
- 参考视频标签是 GSAP：若选用现有 Remotion 工程，可不用 GSAP 时间线，用 `spring` / `E.snap` / 自己的函数等价实现（确定性、可逐帧渲染）。
- `post.json`：`{ "grain": 0, "vignette": 0, "bloom": 0 }` —— 扁平风格不要任何后期质感。

## 五、声音
每次落地一个"啵"（`pop`，音高随弹跳降低）、元素弹出 `tick`、日落 `swell`（短）、字标出现 `jingle`（pluck 上行三音）。

## 六、坑
- 缩放中心不在底部：压扁时球会离开地面。
- 线性运动 = PPT；所有移动都要 easing / spring。
- 加了阴影或渐变就不是扁平风了。
