# 风格 05：逐帧手绘（Frame by Frame）

> 示例状态：随附可运行的 Remotion 画面源码；未编排音轨。下文“声音”是制作建议。

> **每一帧重画 · 线条微微颤动（boil）· 笔刷有粗细 · 水彩色块 · 一拍二的顿**
> 来源（新版文档记载；未附原视频，本次未复核原片与工具标签）：参考视频《十五种 MG 风格》第 01 种（作品「手作 HAND MADE」：火柴划亮，火苗跳下来扭起舞）。
> 工具：`@styles/hand`（+ `@styles/paper` 的纸纹）；示例：`projects/示例_逐帧手绘/`（火柴划亮 → 火苗跳到盒子上跳舞 → 手写片名）。

## 一、一句话认出它
像动画师一张张画出来的：线条每两帧就"抖"一次（沸腾线），线有起笔收笔（两头尖），颜色是没涂满、边缘有水痕的水彩，角色会长出小手小脸，动作有弹性但是一顿一顿的。

## 二、什么题目用它
温暖的小故事、手作感的品牌片、童趣 / 回忆 / 治愈；一个物件拟人化（火苗、杯子、种子）讲一件小事。不适合：数据多、需要精确的图表。

## 三、长什么样
- **线**：深墨色 `#2a211c`，笔刷宽 4~8px，两头按 `sin^0.55` 收尖；每两帧（12fps 的一拍）重新抖一次，幅度 1~2px。
- **色块**：水彩 = 三层错位的半透明填色（各抖 3.5px）+ 一圈更深的水痕边；颜色不填满线框，故意错开。
- **纸**：奶油色纸底 `#f3e9d2` + 纸纹 multiply（`overlayPaper(g, .5)`）。
- **运动**：位置也按 12fps 取样（`Math.floor(t*12)/12`），挤压拉伸（落地压扁），角色动作夸张。
- **字**：得意黑 56px 手写感，每个字按拍轻轻歪一下（`HandSub`）；片名大字也按拍抖。
- 颜色：红 `#d8432f`、黄 `#f6c445`、橙 `#ef7d2a`、蓝 `#4f7cac`、绿 `#6f9a55`、木 `#c98a4b`。

## 四、技术实现方案
**一层全分辨率 `<Canvas2D>`，所有东西每帧重画；随机种子 = 拍号**，所以同一拍内不变、换拍才变（这就是"沸腾线"）。
```ts
import { HAND, onTwos, brush, brushClosed, wash, ellipsePts, teardrop, blob, linePts, HandSub } from '@styles/hand';
const b = onTwos(t);                                   // 12fps 的第几拍（Math.floor(t*12/2)）
wash(g, rectPts, b, HAND.red, seed);                   // 先上色（水彩）
brushClosed(g, rectPts, b, { w: 7, seed });           // 再描线（笔刷）
brush(g, linePts(x0, y0, x1, y1, 10, bend), b, { w: 6 });
```
- `brush` 不是 `stroke()`：把中心线每点沿法线左右偏 `w/2 × 压力` 拼成多边形再 `fill()`，所以能两头尖、中间粗；
  压力 = `sin(π·u)^taper × (0.8~1.2 随机)`，`taper` 小 = 粗细均匀（闭合形状用 .15）。
- `wobble(pts, b, amp, seed)`：每个点加 `(rnd(点序号 + b*31) - .5)*amp*2`，种子含拍号 → 每拍换一次形。
- `wash`：同一形状 3 次 `wobble`（不同 seed）各填一次 `globalAlpha .45×a`，再描一圈 3px 半透明边 = 水痕。
- 形状库：`ellipsePts`、`teardrop`（火苗 / 水滴，`sway` 让尖端摆）、`blob`（云、团）、`linePts`（带弯曲的线）。
- 角色的脸：两个墨点眼睛 + 一条笔刷嘴；手 = 两根笔刷线，按 `sin(t*10)` 挥。
- 性能：控制每帧笔画数；先测代表镜头，再决定并发。
- `post.json`：`{ "grain": 4, "vignette": 0.25, "bloom": 0 }`。

## 五、声音
手作感的真实音效：划火柴（`snip` 改短 + `fire` 起火）、纸张 `paper`、铅笔 `scribble`、卡通 `pop`；不铺底。

## 六、坑
- 抖动每帧都换 = 闪烁；一定按拍（`onTwos`）。
- 水彩填得太准 = 像矢量；要错位、透出底下的纸。
- 笔刷宽度一致 = 像 SVG 描边；压力曲线不能省。
- 整个场景太小会显得空：示例里整体放大 1.45 倍居中。
